# Day 2 Assignment: Style the Two-Page Site

**Repository:** web-foundations-days. **Folder:** day2/. **Deadline:** before Day 3.

## What's checked

- day2/index.html and day2/about.html - copies of the Day 1 pages, each linking the shared style.css inside the <head>, with class="features" added to the features <ul> on the about page.
- day2/style.css - one shared stylesheet with a box-sizing: border-box reset; header styles; the <nav> links laid out in a row with Flexbox (centred, 16px gap, white text, no underline, a visible hover style); a centred <main> with a maximum width; the features list laid out with CSS Grid as responsive cards; styles for the shortcuts table; styled feedback form fields stacked vertically with full width; a transition on buttons; and at least one @media (max-width: 600px) rule.
